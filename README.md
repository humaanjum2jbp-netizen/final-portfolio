# Huma Anjum Portfolio

## Folder structure
- index.html
- css/style.css
- js/script.js

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub
```bash
git init
git add .
git commit -m "Initial website"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## Vercel
Import the GitHub repository in Vercel. This is a static HTML/CSS/JS site, so no build command is required.
